2. Переименование пустым названием

После отключения проверки пустого названия тесты показали, что пробелы, табуляция и NBSP сохраняются вместо прежнего названия. Правило: проверять новое название до изменения задачи и сохранять прежнее, если новое состоит только из пробельных символов. Улика: блок (б) в `evidence/red.txt`, 3 теста упали.

3. Отображение старых пустых задач

4. Название из U+200B

После отключения обработки U+200B символ сохранялся при создании и переименовании. Правило: считать U+200B пустым символом при проверке названия. Улика: блок (г) в `evidence/red.txt`, упали оба соответствующих теста.
